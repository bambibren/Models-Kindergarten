发现阶段
SkillDiscovery.discoverGitHub() 依次调用：
GitRepository.clone()
→
runGitCommand(["clone", ...])
→
spawn("git", args)
repository.resolveCommit()
→
runGitCommand(["-C", root, "rev-parse", ...])
→
spawn("git", args)
repository.listTreePaths()
→
runGitCommand(["-C", root, "ls-tree", ...])
→
spawn("git", args)
安装阶段
SkillInstaller.stageGit() 依次调用：
GitRepository.clone()
→
runGitCommand(["clone", ...])
→
spawn("git", args)
repository.checkout()
→
runGitCommand([..., "sparse-checkout", "init", ...])
→
spawn("git", args)
repository.checkout()
→
runGitCommand([..., "sparse-checkout", "set", ...])
→
spawn("git", args)
repository.checkout()
→
runGitCommand([..., "checkout", "--detach", ref])
→
spawn("git", args)
repository.currentCommit()
→
runGitCommand([..., "rev-parse", "HEAD"])
→
spawn("git", args)
runGitCommand() 是统一的 JS 执行封装；真正启动子进程的是它内部的 node:child_process.spawn("git", args)。
